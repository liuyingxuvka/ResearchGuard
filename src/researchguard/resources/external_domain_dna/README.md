# Installed external-domain DNA examples

This package contains the canonical bounded-scope Attention v7 candidate specification, its independently signed scope-authority record, its four-member native portable composition, and separate native-member and scope-authority producer-descriptor trust-root lists. The composition carries the closed LogicGuard, SourceGuard, TraceGuard, and ExperimentGuard proof inputs required for native replay, so an installed consumer does not reopen compiler temporary files. The authority fixes the target/version/material inventory, the abstract/results-table/results-prose semantic roles and occurrences, every member input/output kind, handoffs, limits, exclusions, and frontier independently of the candidate. The model accounts for all 25 frozen files but claims semantic completeness only for the declared English-to-French BLEU consistency question.

Portable replay proves receipt-identity uniqueness and exact carried bytes only within the one supplied bundle. Without a shared immutable authority or transparency log, it cannot prove that an independently isolated bundle does not contain a conflicting producer-issued receipt under the same identity.

Use `researchguard domain-dna build` with `--native-composition` and, when available, `--scope-authority`; then inspect through one compact member, behavior, object, scope, impact, or reverse query. A carried authority is not automatically trusted. `dna_qualified` requires the caller's explicit trusted authority fingerprint or trusted scope-authority producer-descriptor fingerprint, current authority-derived material replay, exact artifact trust, native-member producer trust, and complete obligation coverage. Production contains no authority private key. Bundle-only replay remains self-consistency, not qualification.
