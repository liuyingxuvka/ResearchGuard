# Safe Trace Output

Keep these layers separate:

- event fact: what happened, when, where, and who;
- explanation: supported mechanism, motive, or interpretation;
- execution/follow-through: what was implemented or operated;
- outcome/impact: what measurably changed;
- counter/limiting evidence and live alternatives;
- future trigger or factual prediction boundary.

For scope transfer, name the current layer, desired wording layer, bridge evidence found/missing, weakest link, safe wording, and unsafe wording. Announcement is not operation; plan is not outcome; forecast is not observation; wholesale/capacity is not retail/terminal impact; local evidence is not national evidence; chronology is not causality.

When sources conflict, preserve the conflict, freshness, proximity, locator/provenance strength, affected layer, and next owner. Do not select the smoothest story. If alternatives remain live, hand that state to LogicGuard for conclusion-tournament review.

Safe example: “Incident A has log, issue, and PR evidence for mitigation; permanent resolution remains outside the current evidence boundary.” Never turn this into “fully resolved” without its own outcome chain.
