## DNA ownership boundary

This blueprint is TraceGuard member-domain DNA: it owns temporal traces, storylines, alternatives, evidence, bounded-causal interfaces, and native closure semantics. It may supply semantic obligations to the TraceGuard subtree under the sole FlowGuard-owned ResearchGuard repository software-DNA root, but it is not a whole-repository software blueprint. Code, test, intent, resource, topology, repository-denominator, seven-layer readiness, canonical-export, installation, and release claims remain with that root and their native evidence owners. Native TraceGuard closure and repository software-DNA readiness therefore stay separate.

Project one deterministic rooted hierarchy from investigation through storyline hypotheses, traces, stages/sequences, events, evidence, sources, entities/resolutions, locations, hypothesis links/relations, causal boundaries/candidates/mechanisms/confounders/scopes, perturbations/ablations, and expected sensitivities. Every child has one containment parent at the next depth; nonownership cross-links are explicit.

Bind Source→EvidenceFact, EvidenceFact→Event, Event→Trace, Trace→Hypothesis, and Hypothesis→BoundedClaim/Handoff interfaces with endpoint fingerprints, payload schema, and current receipt references bound to producer, result, model, and task. Material source, entity, location, event, causal, and perturbation outputs are consumed or explicitly dispositioned. Persist the independent stable-object universe as an exact request contract plus raw native-inventory locator/hash. The request id is content-addressed, the target revision is the independent native-subject fingerprint, and the authority id is bound to the exact raw bytes. Production exposes no trace-model/universe-to-target authoring shortcut. TraceGuard's closed current adapter replays those bytes on issuance and serialized reload; submitted model/universe rows, co-shrunk candidates, and process memory never define authority. Missing/changed local bytes block and unreplayable external material remains unverified.

External expected-target admission fixes the stable-object target and denominator; TraceGuard-native parsing separately interprets the admitted bytes. Anchor and immutable receipt locators/hashes are persistent evidence and cache state is never authority. Direct blueprint use without admission is unverified, and a different target requires a separately admitted anchor. Production has no public or generic target, attestation, or receipt issuer and no inline candidate-authoring path. Impact and reverse trace each perform exactly one current closed native replay over resolved evidence.

Use `researchguard trace blueprint {check|impact|trace|export}`. Mixed unknown ownership suppresses all partial impact. If qualification is not current, return one atomic rejected report with `partial_result_suppressed=true`; ordinary output, path, node, edge, evidence, source, hierarchy, receipt-contribution, causal, and terminal fields stay empty, and only exact qualification/material/authority/receipt gaps plus the claim boundary remain. An unknown output id cannot bypass the gate.

Hierarchy completeness never licenses formal causal identification, an SCM, do-calculus, calibrated treatment effects, or unread source content.
