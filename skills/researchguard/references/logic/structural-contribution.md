# Structural Contribution

For hierarchical artifacts, check not only whether each unit is locally coherent but what it does for its parent, which later unit consumes it, and whether the conclusion recovers it.

For each important unit preserve: stable locator/type, parent goal, unit job, contribution type, importance, child obligations, downstream consumers, conclusion recovery, local logic/source/trace/structural status, repair action, allowed wording, and unsafe wording. A high-importance non-background unit without a parent goal, useful job, downstream consumer, or required conclusion recovery is `orphan`, `missing_downstream_consumer`, or `unrecovered`, not closed.

Audit same-level progression in literature/technology reviews and similar sequences. Adjacent units should extend, narrow, contrast, depend on, or expose a limitation in the prior unit. Parallel summaries that only return to the parent are `missing_sibling_progression` or `parallel_background`; repair with a bridge, reorder, background/appendix treatment, omission, or human review.

Method units must expose design need, selected choice, rejected alternative and reason, implementation consequence, validation consequence, limitation, and downstream use. Figures/tables need intended takeaway, argument role, body explanation, caption/source status, and visual clarity. Rerun the structural contribution audit after material prose or structure changes.
