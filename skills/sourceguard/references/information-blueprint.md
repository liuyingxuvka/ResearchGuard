## DNA ownership boundary

This blueprint is SourceGuard member-domain DNA: it owns target units, gaps, search, sources, anchors, claim uses, lineage, and native closure semantics. It may supply semantic obligations to the SourceGuard subtree under the sole FlowGuard-owned ResearchGuard repository software-DNA root, but it is not a whole-repository software blueprint. Code, test, intent, resource, topology, repository-denominator, seven-layer readiness, canonical-export, installation, and release claims remain with that root and their native evidence owners. Native SourceGuard closure and repository software-DNA readiness therefore stay separate.

The blueprint connects objective → target-unit hierarchy → evidence gap → required source role → search action → observation/source → evidence anchor → qualified gap → claim use or handoff. Target units have typed ports and exact child-output-to-parent-input bindings. Every produced source, anchor, unit output, claim use, and handoff is consumed or explicitly dispositioned.

An independently fingerprinted universe lists the complete target-unit tree and interfaces, gaps, source roles, lineage slots, anchor/bridge requirements, handoffs, and known good/bad cases. Persist the exact request contract and raw target-tree material locator/hash. Its request id is content-addressed, its target revision is the independently authored target-subject fingerprint, and the authority id is bound to the exact raw bytes. Production exposes no graph/universe-to-target authoring shortcut. SourceGuard's closed current guard-contract/target parser replays those bytes on issuance and reload and compares them with graph and universe. Process memory, submitted universe rows, and co-shrunk graph/universe values provide no authority. Missing/changed local material blocks, while external material that cannot be replayed remains unverified. Source revisions bind content, retrieval request, provider/revision, lineage, and retrieval time. Anchors bind locator, anchor/source content, extractor/revision, and observation fingerprints. Naked ids do not prove current content.

External expected-target admission fixes the information target and denominator; SourceGuard-native parsing separately interprets the admitted bytes. Anchor and immutable receipt locators/hashes are persistent evidence and cache state is never authority. Direct blueprint use without admission is unverified, and a different target requires a separately admitted anchor. Production has no public or generic target, attestation, or receipt issuer and no inline candidate-authoring path. Impact and reverse trace each perform exactly one current closed native replay over resolved evidence.

Use `researchguard source blueprint {check|impact|trace|export}`. Impact and reverse trace each consume exactly one current native blueprint qualification, including the purpose receipt and replayable material authority. Failed, stale, unverified, or not-run qualification suppresses ordinary affected/unaffected lists and keeps reverse closure incomplete with its exact gaps. Once admitted, a changed source or anchor invalidates only declared qualifications, gaps, stop decisions, claim uses, handoffs, and parent target units. Unknown ownership suppresses all partial results. Reverse trace must reach the exact target unit, gap, source-role obligation, search action, source revision, anchor locator/content identity, qualification, and handoff boundary.

Reverse trace must finish that single qualification before validating or resolving the requested claim use, building edge sets, selecting anchors/gaps/actions, or walking target-unit ancestry. A non-current result returns one atomic rejected report with `partial_result_suppressed=true`; target paths/interfaces, gaps, roles, actions, observations, sources, anchors, qualifications, handoffs, and terminal fields stay empty, while exact qualification/material/authority/receipt gaps and the claim boundary remain. An unknown claim-use id is not a target-resolution exception until qualification has passed.

Completeness proves the modeled information-discovery and qualification chain only. It does not prove source truth, final argument support, temporal reconstruction, or causal meaning.
