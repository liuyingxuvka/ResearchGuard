# Safe Output

State what SourceGuard actually established:

- a selected search is expected to close named gaps;
- a source is a candidate until content, provenance, role, and claim-use checks pass;
- a source can support X but cannot support Y;
- a citation/footnote needs an exact source-role and wording boundary;
- repeated lineage is not independent support;
- an announcement still needs execution/outcome evidence;
- a forecast/model/context source guides interpretation but is not observed outcome evidence;
- a permission-gated source is an access gap;
- structural-role notes are handoff context, not final artifact ownership;
- utility ranks search value, not factual truth.

Never say a search result proves the claim, a bibliography supports the paragraph, a locator closes a semantic gap, many mentions are independent, a regional/planning/wholesale/forecast source supports national/retail/outcome/fact wording, or SourceGuard decided the final argument.

Return `continue_search`, `stop_sufficient`, `blocked_unresolved_critical`, or `not_run` with marginal value, cost, budget, critical gaps, and selected next search visible. This is a planning decision, not a truth claim.
