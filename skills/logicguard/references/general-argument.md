# General Argument Route

Use this route for ordinary or mixed LogicGuard work after no narrower internal route owns the first action.

## Model shape

Model the reasoning target with explicit `Claim`, `Evidence`, `Warrant`, `Assumption`, `Rebuttal`/`Undercutter`, `Qualifier`/`Limitation`, `Method`, `Result`, and scope nodes as relevant. Keep confidence, edge weight, and importance distinct. Evaluate the model, inspect root state and cycles, run diagnostics, and create a gap ledger when the next repair is unclear.

For non-trivial work, use a model mesh shaped by the artifact rather than one shallow top-level graph. Natural units become countable model cards; high-importance cards are not acceptable leaves. Label a limited model `round-0 skeleton`, `partial`, or `under-modeled` instead of claiming comprehensive coverage.

For important conclusions, build a conclusion tournament: preferred conclusion, steelman opposition, live alternatives, relevant model lenses, expert-role boundaries, robustness tests, winner, and allowed wording. A structural winner is not factual truth.

## First native sequence

1. Freeze the claim or artifact purpose and current coverage.
2. Validate an existing model or create the smallest artifact-appropriate model.
3. Evaluate and diagnose local support, warrants, assumptions, boundaries, opposition, causal transfer, and scope.
4. Expand important nodes or record exact gaps and typed SourceGuard/TraceGuard handoffs.
5. Run fragility/counterexample checks for important conclusions.
6. License wording as `assert`, `qualify`, or `withhold` within the current structural boundary.

Use `task-model-maturation.md` when a prediction-driven revision is required and `broad-depth-and-closure.md` before broad claims.
